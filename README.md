# ゆとシートⅡ → ココフォリア変換

アリアンロッド2Eのキャラクターシートから、ステータス・パラメータ・チャットパレットを生成するブラウザ用ツールです。効果文から読み取れた補正を確認して選び、生成後の文章も自由に編集できます。具体的な操作はアプリ内の「使い方」を参照してください。

## 開発と確認

Node.js 24（`.nvmrc`）を使用します。依存関係は `package-lock.json` に固定しています。

```sh
npm ci
npm run dev
npm run check
npx playwright install --with-deps chromium
npm run test:browser
```

`check` は型の確認、全単体テスト、本番ビルドを実行します。単体テストはTypeScriptを一度だけコンパイルし、同じ成果物を共有します。各テストファイルを `node tests/…test.cjs` で個別実行することもできます。ブラウザテストは合成データを使い、実在のキャラクターシートは公開しません。`npm run format` でコードの書式を整えます。

GitHub Actionsは、依存関係のインストール、全テスト・ビルド、ブラウザ操作の確認が成功した場合のみmainのサイトを公開します。Pull Requestでは確認だけを実施し、公開しません。

## コードの流れ

- `ytsheet/`・`items/`・`utils/`：入力の読み取り。表示用の文字復元と解析用の表記統一を区別します。
- `resources/`：使用回数、フラグ、消耗品などの区別とリセット方針。
- `palette/`：宣言・判定・効果の挿入先を持つ内部文書を組み立てます。
- `calculation/`：補正候補、式の描画、手編集範囲の追跡。文字列入力用の互換処理も残しています。
- `output/generator.ts`：入力を一度解析し、新規出力・保存・更新で共有する生成処理。
- `editor/`・`main.ts`：画面と編集操作。使い方の本文は `editor/help.ts` に置きます。
- `session/`：保存時の基準、手編集後の内容、更新候補を比較します。比較の基準を現在の生成結果で無断に置き換えません。

## 変更時に守ること

「続きから編集」は保存した内容をそのまま開きます。「更新を反映」は変更点を確認後に取り込み、HP・MP・フェイト・使用回数を新しい上限に戻します。生成した内容と手編集が競合した場合は選択を求めます。異なる生成形式の保存には案内を出します。保存ファイル形式v1と既存の保存キーは維持しています。

表記や見出しを変えるだけの修正で、保存済み補正の識別キーを変えないでください。旧版の保存、手編集・削除・並べ替え、短縮名、補正の選択を含むテストを維持してください。ゲーム上の適用条件や二重加算を自動で完全に判定するツールではありません。
